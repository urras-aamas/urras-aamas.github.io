Central Thesis
Classical metareasoning chooses among computations from a menu that is given in advance. Generative agent societies break that assumption: they can write skills, spawn agents and create sub-societies, so every decision can change the action set available to all later decisions. We argue this calls for a theory of recursive metareasoning.
TL;DR URRAS routes uncertainty into Think, Consult, Learn or Reorganize actions by their estimated value of computation, and lets hard subproblems recursively create child societies governed by the same controller.
Overview

Abstract

When an agent is uncertain, should it think longer, consult another agent, acquire a new skill, reorganize its team, or admit that further computation is unlikely to help? Classical metareasoning answers such questions by weighing the expected value of a computation against its cost, but it assumes that the set of available computational actions is known and fixed. Generative agent societies violate this assumption: they can synthesize skills, open communication channels, instantiate specialists and entire sub-societies, and thereby change the very action space over which future metareasoning operates. We propose Uncertainty-Routed Recursive Agent Societies (URRAS) as a research agenda for metareasoning in such self-modifying systems. URRAS organizes computation around four escalating interventions (Think, Consult, Learn, Reorganize) and lets hard subproblems recursively instantiate child societies governed by the same controller. Uncertainty is treated not as an objective to minimize but as diagnostic evidence for estimating the value of further computation. This perspective exposes new multi-agent problems: identifying why a society is uncertain, allocating budgets across nested societies, assigning credit across recursive interventions, eliciting truthful uncertainty reports from strategic agents, and keeping self-modifying organizations stable. We outline these challenges and state falsifiable predictions by which the paradigm can be tested under matched inference budgets.

Why diagnosis, not uncertainty, drives the choice

6 · Why uncertainty is evidence, not the objective

An uncertainty-minimizing controller finds the cheapest way to make agents agree. In language-agent groups that is often conformity.

✗ Minimize uncertainty

  • Agents disagree → uncertainty is high
  • Cheapest fix: let the majority persuade the rest
  • Disagreement vanishes, confidence rises
  • Confidently wrong (echo chamber)

✓ Maximize value of computation

  • Agents disagree → treat it as a symptom
  • Diagnose the source: reasoning, knowledge, skill…
  • Pick the action whose estimated value beats its cost
  • Act, or Abstain if irreducible

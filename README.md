# URRAS project page

Project page for **Think, Consult, Learn, Reorganize: Recursive Metareasoning for Self-Modifying Agent Societies** (AAMAS 2027 Blue Sky Ideas Track, under review).

Static site on the Academic Project Page Template (same styling as the bioMoR page).

- `index.html` is the whole page; `static/images/overview.png` is Fig. 1 rasterized from the paper PDF at 300 dpi.
- `static/paper/paper.pdf` is the **anonymized review version**.

Open items: per-author affiliations, arXiv link, and a de-anonymized PDF.
Do not publish while the paper is under double-blind review unless the AAMAS 2027 policy allows it.
